# 電験三種 学習室 — 公開配信用

2017〜2026年度、14回・四科目の公式過去問を使う学習サイトです。

問題・解答の著作権は一般財団法人 電気技術者試験センターに帰属します。教育目的での利用条件に基づき、問題ごとに年度・期・区分・科目を表示しています。原本PDFの画像化と大問ごとの切り出しを行い、内容は変更していません。

公式の問題・解答と使用条件: https://www.shiken.or.jp/chief/third/qa/

独自解説と要点ノートは同センターの監修ではありません。法規は出題当時の正答で採点します。回答履歴はブラウザー内に保存し、配信リポジトリやサーバーには送信しません。

このリポジトリは公開用ファイルのみを収録します。ビルド用スクリプト、検証画像、端末の実際の学習履歴は含みません。
